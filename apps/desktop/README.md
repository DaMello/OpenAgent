# Desktop app

Target: Tauri + React.

The desktop UI will mirror the visual language of Qwen Image Local while becoming a full personal-agent shell:

- left sidebar: chats, search, settings;
- center: chat timeline + composer;
- right panel: Browser / Tasks / Files;
- reasoning selector: Instant / Medium / High / Max / Ultra Think;
- Plan Mode toggle;
- context meter and manual Compact action;
- approval cards for privileged actions;
- local browser activity visible in real time.

The Python harness is intentionally usable before the desktop app exists.
